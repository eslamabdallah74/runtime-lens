# Explore

- **Runtime Lens: Recent Requests** focuses every label on one request (also from the status bar).
- **Runtime Lens: Slowest Methods** ranks methods by time per request.
- **Runtime Lens: Toggle Inline Annotations** hides or shows the labels.
- **Runtime Lens: Clear Data** starts fresh.

Labels always show the latest run of each request, so fix, re-run, and watch the warning disappear.
